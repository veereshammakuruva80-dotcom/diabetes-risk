# AI-Based Diabetes Risk Prediction and Health Recommendation System

An integrated clinical informatics and machine learning solution for diabetes risk estimation and personalized health recommendations.

## Tech Stack
- **Frontend**: HTML5, CSS3, JavaScript
- **Backend**: Python Flask
- **Machine Learning**: Scikit-learn, Random Forest Classifier
- **Data Processing**: Pandas, NumPy
- **Database**: MySQL
- **Model Storage**: Joblib
